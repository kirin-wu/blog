# 🧭 新疆北疆 + 伊犁 12 天游｜行程表（2 人）

| Day | 行程路线 | 主要内容 |
|---|---|---|
| Day1 | 南京 → 乌鲁木齐 | 飞机抵达乌鲁木齐，休息适应 |
| Day2 | 乌鲁木齐 | 市区游玩，品尝新疆美食 |
| Day3 | 乌鲁木齐 → 阿勒泰 | 火车（软卧），抵达阿勒泰 |
| Day4 | 阿勒泰 | 将军山滑雪（门票 + 雪服雪板） |
| Day5 | 阿勒泰 → 禾木 | 拼车前往禾木，游览禾木村 |
| Day6 | 禾木 → 喀纳斯 | 拼车前往喀纳斯，游览喀纳斯湖、三湾 |
| Day7 | 喀纳斯 → 白哈巴 | 拼车前往白哈巴，骑马体验 |
| Day8 | 白哈巴 → 阿勒泰 | 拼车返回阿勒泰市区 |
| Day9 | 阿勒泰 → 伊宁 | 飞机直飞伊宁 |
| Day10 | 伊宁 → 赛里木湖 | 跟团两日游 Day 1，湖区游览拍照 |
| Day11 | 赛里木湖 → 伊宁 → 乌鲁木齐 | 跟团返回伊宁，夜火车返乌鲁木齐 |
| Day12 | 乌鲁木齐 → 南京 | 水会休息，下午飞机返程 |
